# NaviSoft

**Software para organizar a operação e apoiar o crescimento das empresas.**

A NaviSoft desenvolve aplicações para gestão empresarial e soluções sob demanda. Reunimos ferramentas para estoque, relacionamento comercial e agendamento, com foco em uma experiência clara, integração entre produtos e evolução contínua.

## Nossas soluções

| Produto | Para que serve |
| --- | --- |
| [NaviStock](https://stock.navisoftware.com.br) | Gestão de produtos, estoque, depósitos, compras, vendas e inventários. |
| [NaviCRM](https://crm.navisoftware.com.br) | Relacionamento com clientes, oportunidades, propostas, contratos e acompanhamento comercial. |
| [NaviScheduler](https://scheduler.navisoftware.com.br) | Organização de agendas, serviços, profissionais e reservas. |

A suíte conta com o **NaviAuth**, responsável pela identidade e pelo acesso aos produtos, e o **NaviConsole**, central interna de administração e monitoramento. O **NavisoftHub** apresenta as soluções e reúne os canais de contato da empresa.

## Como trabalhamos

- Desenvolvemos produtos próprios e software sob demanda, conforme as necessidades de cada projeto.
- Priorizamos interfaces acessíveis, informações úteis e fluxos que facilitem o trabalho diário.
- Tratamos autorização, isolamento dos dados e rastreabilidade como parte da arquitetura.
- Mantemos frontend e backend independentes, com contratos e responsabilidades definidos.
